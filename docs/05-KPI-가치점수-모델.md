# 05. KPI 가치 점수 모델

기획서 §③(KPI 점수 계산)과 첨부 이미지의 계산식을 **그대로 코드로 옮긴 것**입니다.
구현: [`app/js/kpi.js`](../app/js/kpi.js)

## 1. 계산 파이프라인

```
로데이터(누적 카운트)  →  경기당/비율 지표  →  표준화(Z)  →  가중합  →  점수화(T)
```

1. **로데이터 확인** — 클릭으로 쌓인 누적 카운트를 경기 수로 나눠 "경기당" 지표로 변환.
2. **표준화** — `Z = (선수값 − 리그평균) / 리그표준편차`
3. **가중치 적용** — `KPI_Z = Σ (Zᵢ × weightᵢ)`
4. **점수화** — `T = 50 + 10 × KPI_Z` (평균 50점, 표준편차 ±10점), 0~100 클램프.

### 기획서 예시 재현 (기회 창출 능력)
| 단계 | 값 |
|---|---|
| 로데이터 | 이승원 빅찬스 3.0 / 키패스 0.8 |
| 리그 평균 | 빅찬스 3.75 / 키패스 1.47 |
| 표준화 | 빅찬스 Z −0.26 / 키패스 Z −0.95 |
| 가중치 | 빅찬스 0.6 / 키패스 0.4 |
| 가중합 | (−0.26×0.6)+(−0.95×0.4) = **−0.53** |
| 점수 | 50 + (10×−0.53) = **44.7점** ✅ |

> `kpi.js`의 리그 표준편차는 이 예시에서 **역산**했습니다.
> 빅찬스 std = (3.0−3.75)/(−0.26) ≈ 2.885, 키패스 std = (0.8−1.47)/(−0.95) ≈ 0.705 → 44.7점 재현.

## 2. 5개 KPI 정의 (기획서 §①)

| KPI | 하위 지표 (가중치) |
|---|---|
| **기회 창출** | 경기당 빅찬스(0.6) + 경기당 키패스(0.4) |
| **득점 능력** | 경기당 득점(0.6) + 득점 전환율(0.4) |
| **연계 능력** | 패스 성공률(0.5) + 경기당 키패스(0.5) |
| **수비력** | 경기당 태클(0.5) + 경기당 인터셉트(0.5) |
| **체력** | 경기당 터치 수(0.5) + 경기당 경합 승리(0.5) |

- 기획서가 명시한 가중치는 기회 창출(0.6/0.4)뿐이라, 나머지는 0.5/0.5 기본값으로 두고
  **`REFERENCE` 테이블에서 언제든 조정** 가능하게 했습니다. (기획서: "가중치는 평가 기준에 따라 조정 가능")

## 3. 리그 기준값의 위치 (중요)

- 기준(mean/std)은 **코드가 아니라 데이터**입니다. `kpi.js`의 `REFERENCE`, 프로덕션에선 `kpi_reference` 테이블.
- 기획서 전제: *2025 K리그 1~25R, 동일 포지션 10명(상위3/중위4/하위4)* 표본.
- ⚠ 기획서 주석대로 출처가 공식 기관이 아닌 **Sofascore 기록값** → 신뢰도 제한적. 기준값은 **지속 보정 대상**.
- 유소년 수준에 맞추려면 K리그 성인 평균을 그대로 쓰지 말고 **연령·리그 보정 계수**를 곱해야 함(향후).

## 4. 왜 T-score(50±10)인가

- 서로 단위가 다른 지표(빅찬스 개수 vs 패스 성공률 %)를 **한 자에 올려 비교**하기 위해.
- 50점 = 리그 평균, 60점 = 평균보다 1σ 우수. 에이전트가 직관적으로 "평균 이상/이하"를 즉시 판단.
- 레이더에서 5각형이 클수록 올라운더, 특정 축만 튀면 스페셜리스트 → **한눈에 선수 캐릭터** 파악.

## 5. 확장 아이디어 (향후)

- **정성 평가 통합**: 8개 별점을 6번째 축 또는 종합점 보정 계수로 편입.
- **성장 그래프**: 라운드별 T-score 추이 → "상승 곡선"을 별도 지표로.
- **유사 선수 매칭**: 5차원 벡터 코사인 유사도로 "이 선수와 비슷한 유형" 추천.
